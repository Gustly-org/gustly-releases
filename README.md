# Gustly app downloads

The Android app for [Gustly](https://www.gustly.org): find the right kite spot in seconds, from the beach.

Get it at **https://www.gustly.org/download/android**, which always points at the newest `gustly.apk` in [Releases](https://github.com/Gustly-org/gustly-releases/releases/latest). Each release lists the APK's size and SHA-256 so you can check your download. The iPhone app is on TestFlight: https://www.gustly.org/download/ios.

This repo holds release files only; they are built and published by Gustly's release workflow.
